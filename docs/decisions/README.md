# Architecture decisions

Record significant changes to model contracts, persistent state, graph schema, AI orchestration, privacy, safety, authentication, migration or hosting.

Create files named `0001-short-title.md`, `0002-short-title.md`, etc., with:

- **Status:** proposed / accepted / superseded
- **Problem and constraints**
- **Decision**
- **Alternatives considered**
- **Security, safety, and data consequences**
- **Migration, rollback and test strategy**
- **Open questions**

Acceptance requires maintainer review. Refer back to decisions from relevant PRs and update the roadmap if sequencing changes.
